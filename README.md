# M7-updates

Openbare updatelijst voor de WordPress-plugins van M7 Branding. Hier staan alleen de installeerbare zips
(alle uitgebrachte versies) en `manifest.json`. De broncode staat in een privérepository.

Sites met een M7-plugin kijken twee keer per dag in `manifest.json`. Een nieuwe versie verschijnt als gewone
WordPress-update en in M7 > Markt; bijwerken gebeurt nooit automatisch. Oudere versies blijven staan zodat je
in de Markt via "Andere versie" kunt terugzetten.
